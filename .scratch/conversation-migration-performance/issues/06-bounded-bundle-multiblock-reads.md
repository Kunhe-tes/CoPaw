# 06: 安全复用 bundle 打开与索引解析

**What to build:** 迁移正文预取及关联证据读取对同一 bundle 一次安全打开、一次解析索引并读取多个请求块，减少 NAS 小操作且保持完整性保护。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 提供有界多块读取并接入运行时正文预取、同 publication 消息读取和适用的 import plan/恢复证据路径，保留单块兼容接口。
- [ ] 当前读取操作复用同一受限文件描述符及解析结果，不建立跨 source、跨命令的长期正文或证据缓存。
- [ ] 每个 extent 校验边界、长度和 publication 身份，维持索引/正文一致性及既有文件状态复查契约。
- [ ] 拒绝软链接、越界、特殊文件、截断及异常替换；覆盖同大小替换、读取中修改与取消，资源正确关闭和排空。
- [ ] 多块总字节、解析膨胀及 IO 并发计入共享预算，保留 fsync、最终源复查和全量语义验证。
- [ ] 经现有迁移入口验证历史、归档、分享及恢复结果一致，计数证明单次多块读取索引只解析一次；本地延迟测试不宣称真实 NAS 放行。
