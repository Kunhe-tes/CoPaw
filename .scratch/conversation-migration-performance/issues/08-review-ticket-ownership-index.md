# 08: 失败 source 自动重审复用票据归属分析

**What to build:** 一次 migrate 对多个失败 source 自动重审时，复用有界票据归属分析，避免逐 source 全扫作业，仍严格保护部分提交和已发布数据。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 在同次受锁保护的重审中建立有界磁盘归属索引或等价分析，完整覆盖实体、批次、分享和 retention 等现有票据规则。
- [ ] 维持零业务数据、零迁移票据才可修订证据；已有部分提交且证据未变可续跑，证据改变继续阻断。
- [ ] 保留 legacy share、runtime ID、归属不明及孤儿业务行处理，不因索引漏项而放行。
- [ ] 写入、证据修订、映射替换或 owner 改变后正确更新或失效；不跨命令沿用证明，不读取已发布 source 旧输入。
- [ ] 通过自动重审入口验证多个坏 source、正常同租户 source、部分提交、输入变化和共享故障，重审次数与部分成功语义不变。
- [ ] 计数证明多个候选不再各自全扫作业票据，磁盘和内存受预算限制且异常时正确清理。
