# Domain Docs

## Layout

本仓库使用单上下文布局：

- 领域术语：根目录 `CONTEXT.md`。
- 架构决策：`docs/adr/`。

本次不重命名现有领域文档。以后如明确迁移为 `GLOSSARY.md`，须同步更新本配置；两者同时存在时不得静默选择冲突定义。

## Consumer rules

- 分析代码前，阅读与任务相关的领域术语和 ADR。
- 文档不存在时继续执行，不预先创建空术语表。
- 在 spec、issue 和实现中使用领域文档定义的术语。
- 与既有 ADR 冲突时明确指出，不静默覆盖。
- 术语存在实际缺口时，再通过领域建模补充。
