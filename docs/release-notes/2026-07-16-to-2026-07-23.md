# CoPaw 周度更新

**时间范围：2026-07-16 ～ 2026-07-23**

本次共审阅 124 条提交（含合并、测试与文档），以下按用户可感知的最终效果归并。

## ✨ 亮点

- 新增异步任务中心，可集中查看任务进度、状态、执行人及详情。
  - 入口：**洞察中心 → 异步任务中心**（`/monitor/tasks`）。
  - 交互：按状态、任务类型、标题/摘要/任务 ID 筛选；点击任务标题查看详情。

- 对话支持“纯内容模式”，适合嵌入第三方页面或专注阅读。
  - 入口：对话页 `/chat/{chatId}?showContentOnly=true`。
  - 交互：隐藏全局导航与非必要界面，仅展示当前会话内容；在会话内切换或导航时保持该模式。

- 支持在发送消息前显式选择要使用的技能。
  - 入口：**对话页输入框 → 输入 `@`**。
  - 交互：搜索并选中技能，选中的技能以标签显示，可删除；本轮对话会按所选技能执行。

- 定时任务看板补充客户接触效果指标。
  - 入口：**洞察中心 → 定时任务概览**（`/analytics/cron-job-overview`）。
  - 交互：在分行排行中查看“接触客户数”“客户接触率”等指标，并可点击分行继续下钻。

## 🚀 新增特性

- 技能管理支持工作区布局迁移与禁用技能管理，技能启停时会自动迁移到正确位置并保持状态一致。
  - 入口：运维 CLI：`swe skills migrate-layout --check` / `--apply`。
  - 交互：先检查迁移影响，再确认执行；支持回滚保护。

- 新增技能 RPC 查询接口，便于外部系统按统一方式发现和查询可用技能。
  - 入口：API 集成入口，无新增控制台页面。

- Hook 可在工具调用前或后明确终止当前 Agent 回合。
  - 入口：Hook 配置的 `PreToolUse` / `PostToolUse` 处理器。
  - 交互：处理器返回 `decision: "stop"` 后，系统展示终止原因并停止继续调用模型或执行后续工具。

- Shell 工具输出采用统一的实时展示与截断策略。
  - 入口：对话中由 Agent 执行 Shell 工具时自动生效。
  - 交互：保留输出首尾内容并提示截断，避免超长日志拖慢或淹没对话。

- 已接入招乎渠道的用户获得通道配置与访问流程适配优化。
  - 入口：招乎相关会话与配置流程自动生效。

## ⚡ 优化

- 异步任务、定时任务与批调度列表的筛选、分页和刷新体验更稳定；运营看板的分页条数选择可正确生效。
- 技能市场的启用、禁用、分发和重新注册流程更一致，降低“技能存在但不可用”或状态丢失的概率。
- 技能统计过滤工具类技能，业务看板的技能使用数据更聚焦于实际业务技能。
  - 入口：**洞察中心 → 运营看板**（`/analytics/business-overview`）。
- `get_users` 查询补充耗时日志并修正机构参数处理，提升用户与机构数据排查效率。
- OpenCLI 运行时凭据可自动注入受控执行环境，减少工具调用时的手工配置。

## 🐛 修复

- 修复纯内容模式在会话切换、页面导航时失效，以及展示状态不同步的问题。
- 修复显式技能选择未正确传递到后端的问题。
- 修复技能工作区清单异常、空名称、外部字段丢失、符号链接回滚和并发生命周期切换等问题；异常清单现在会安全拒绝处理。
- 修复技能市场中禁用包、隐藏注册技能、已重新分发包的可用状态与路径解析问题。
- 修复定时任务子任务默认完成状态及通知开关默认值，避免错误提醒或遗漏提醒。
- 修复批调度浏览稳定性、用户查询参数顺序与 BBK 标识歧义。
- 修复执行链路与 B3 Trace ID 混用，提升链路追踪与问题定位准确性。
- 修复 Hook 在审批后未正确停止、排队审批被重复执行的问题。
- 修复工具输出边界不统一的问题，避免超大 Shell 输出影响对话稳定性。
