# 定时任务保存并同步子任务

1. 在 Scheduler 更新请求中加入保存范围。用现有分发测试数据库验证普通保存、整组同步和日期清空，旧请求维持原接口行为。
2. 在定义发布事务中同步日期并登记子任务更新。复用分发处理器和版本检查，验证保留子任务身份、独立字段和既有散列偏移。
3. 在基本配置页并列展示两个保存动作。用 `ManagedJobEditor.test.tsx` 验证表单可编辑、两种请求和日期单独保存，复用分发结果界面展示同步进度。
4. 执行 Scheduler 定向回归、Console 定向测试和类型检查，检查浏览器兼容性及最终差异。
5. 父任务修改 Cron 表达式、时区或可执行日期时，普通保存前提示同步范围，「保存并同步子任务」直接提交。验证取消保留草稿，普通保存同步这三个字段的变更，其他基本配置按所选按钮处理。
