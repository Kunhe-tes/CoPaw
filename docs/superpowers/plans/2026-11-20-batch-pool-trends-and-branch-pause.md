# 批调度趋势、子任务筛选与分行暂停规则

按仓库约定在主线程实施，使用针对性回归验证各入口。

1. [x] 看板顶栏按分发子任务状态筛选批次，列表、全局指标和失败汇总采用相同条件。批次详情可独立按异步子任务状态筛选执行成员。
2. [x] 未读自动暂停优先按个人资料中的分行匹配规则，缺配置沿用渠道默认。系统配置支持编辑分行启用状态和阈值。
3. [x] 点击模型池打开趋势浮层。桌面端四图按 2×2 排布，窄屏单列，时间轴联动。共享容量和积压使用历史采样，新版批执行结果与派发尝试使用数据库记录。
4. [x] 验证 Monitor、SWE 和 Console 相关回归、生产构建及浏览器基线。

累计结果按所选区间受理的新版批执行统计，同一个成员的每次业务尝试独立计数。派发请求按已登记的派发事件统计，其中重试含业务重跑与传输重投。分行规则优先读取任务所属用户在当前来源的个人资料，资料缺失时使用任务保存的分行代码。
