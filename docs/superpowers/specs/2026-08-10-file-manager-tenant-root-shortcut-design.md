# 文件管理器租户根目录快捷方式设计

**状态：已确认，待实现**

## 目标与边界

在聊天页文件管理器的快捷栏中，紧接“工作目录”新增“根目录”。打开
文件管理器时仍默认激活“工作目录”。“根目录”提供与工作目录一致的
浏览、预览、上传、编辑、下载和归档删除能力。

本变更仅扩展聊天文件管理器。它不改变 Agent 的工作目录、shell 工具的
路径边界、租户配置目录，或既有的上传、下载、对话和回收站快捷方式。

## 已确认的路径模型

`/opt/deployments/app/working/` 是根目录快捷方式的受控基目录。每个请求
访问当前有效租户作用域的独立目录：

```text
/opt/deployments/app/working/<有效租户作用域>/
```

`<有效租户作用域>`必须沿用现有 tenant/source 的规范化解析：默认用户在
携带 source 时使用 source-scoped 作用域；其他用户保持现有有效租户作用域
语义。不得使用客户端传入的原始 tenant ID 直接拼接路径。

后端根标识命名为 `source_scope`，而 UI 显示名称为“根目录”。这样避免将
业务根与操作系统根目录 `/` 混淆。

## 设计

### 前端

- 在 `shortcutRoots` 中将“根目录”置于“工作目录”之后。
- 扩展 `FileManagerRoot` 的 TypeScript 联合类型以包含 `source_scope`。
- 保持 `useState<FileManagerRoot>("working")` 不变，因此首次打开、重新
  打开以及尚未手动切换时均选中工作目录。
- 现有的切根、面包屑、三栏锚点、脏编辑器拦截、上传、预览、下载和归档
  操作继续透传根标识，无需新增页面状态或独立 UI 流程。

### 后端

- 扩展 Python `FileManagerRoot` 枚举和同权 capability 映射。
- 请求处理器仍先通过 `resolve_file_manager_workspace_dir()` 验证请求所属的
  Agent 工作区；同时由服务端根据同一请求上下文解析 `source_scope` 的
  租户目录。浏览器只可传根标识和相对 POSIX 路径，不能传受控根的绝对路径。
- `FileManagerService` 接收该租户的 source-scope 根目录映射。其余文件管理
  操作仍使用现有的根枚举和相对路径契约。
- 在租户目录初始化期间创建 source-scope 目录。为了兼容已有租户，首次
  文件管理器访问可安全地补建当前租户目录；目录缺失不可导致上传能力失效。

### 回收站与恢复

根目录删除沿用当前治理归档协议，并写入当前 Agent 工作区已有的回收站。
该 Agent 工作区本身已由请求的有效租户作用域验证。归档元数据用专用的
`source_scope` 根前缀记录原路径。恢复时先解析该前缀，再回到同一租户
作用域的受控目录。此设计保证：

- 工作目录、上传目录、下载目录和根目录的归档条目可共存在当前 Agent
  工作区的回收站；
- 恢复不会落入工作目录，也不会越过当前租户目录；
- 其他租户既不能查看、恢复，也不能永久删除这些条目。

### 路径安全与并发

- source-scope 基目录是部署常量，租户段来自现有规范化作用域解析；绝不
  接受或拼接未验证的用户输入。
- 保持现有相对路径校验、`O_NOFOLLOW`、基于目录文件描述符的打开方式和
  常规文件限制。`..`、绝对路径和任意层级的符号链接均应失败。
- 分页游标仍绑定根标识、相对目录与查询条件；`source_scope` 游标不得用于
  `working`，反之亦然。
- 根目录的变更使用当前租户工作区锁和归档事务，因此同一租户作用域的删除、
  恢复和永久删除保持串行。

## 备选方案

1. **推荐：独立的 `source_scope` 受控根。** 满足指定部署路径、租户隔离和
   与工作目录同权的需求，复用已有文件管理器协议。
2. 将该入口指向工作目录的子目录。实现较小，但不满足指定的外部绝对路径。
3. 提供可配置的根路径。增加部署灵活性，但当前没有该需求，会扩大配置和
   迁移范围。

## 测试策略

- 后端单元测试：根枚举和 capability、路径映射、缺失目录准备、分页游标
  根绑定，以及根目录的列表、读取、上传、编辑、下载、归档、恢复和永久删除。
- 租户隔离测试：同一 tenant 的不同 source 及不同 tenant 都只能访问各自
  `/opt/deployments/app/working/<有效租户作用域>/`；尝试父路径、绝对路径、
  符号链接和跨根游标必须失败。
- 路由测试：所有文件管理器端点均接受 `source_scope` 并在请求的有效租户
  作用域中操作。
- 前端测试：快捷栏 DOM 顺序为“工作目录、根目录、上传目录…”，默认工作
  目录的 `aria-pressed` 为 `true`，切换根目录后请求参数为 `source_scope`，
  并覆盖该根目录下的上传、编辑与删除入口可用。

## 不在本次范围

- 不把根目录暴露给 Agent shell、搜索或其他非文件管理器工具。
- 不迁移既有工作目录内容。
- 不新增管理员配置界面或运行时可变的根路径设置。
