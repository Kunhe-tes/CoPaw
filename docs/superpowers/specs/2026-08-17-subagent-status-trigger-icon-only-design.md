# 子代理状态入口仅图标展示设计

## 目标

当聊天页触发子代理并显示悬浮监控入口时，收起态入口只展示原有的三点活动图标，不再展示“`N 个助手运行中`”或“查看助手状态”文字。用户仍可通过点击入口打开助手运行状态面板。

## 方案

在 `console/src/pages/Chat/components/SubAgentRunMonitor/index.tsx` 的收起态触发按钮中移除文字 `span`，保留三点 `activityDots`。按钮继续使用现有 `aria-label="助手运行状态"`，因此视觉收窄不会损失键盘访问或屏幕阅读器语义。现有 `activeCount` 计算、轮询、刷新事件和展开状态不变。

不使用 CSS 隐藏文字，也不抽取新的通用按钮组件：前者会保留无必要的 DOM 内容，后者超出单点展示调整的范围。

## 验证

- 组件测试验证存在运行中子代理时，收起态按钮可通过 `aria-label` 找到，且不渲染运行数量或“查看助手状态”可见文字。
- 组件测试验证点击该图标按钮仍可展开“助手运行状态”面板。
- 运行子代理监控组件测试、Console 类型检查/构建和相关 lint/格式检查。
