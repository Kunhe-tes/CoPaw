## Why

财富工作台发布人员已有精确到 SAP 用户 ID 的名单。逐个按机构选人耗时，也无法覆盖名单中指定的外分行收件人。

## What Changes

- 为白名单内可选择分发目标的发布人提供「上传 Excel 名单」。新建时默认选 Excel，可切回「按机构选人」，两种方式互斥。
- 非白名单用户继续使用原有界面、分发规则和发布流程。Excel 权限与运维模式独立。
- 浏览器读取模板中的客户经理ID，客户经理姓名可选填。人员信息以外部智拓接口返回为准。发布前按分行查看人员卡片，支持搜索及剔除个别人。
- 修改规划时，白名单用户可以直接移除已有人员，也可以上传增量 Excel 追加或上传完整 Excel 替换。
- 跨分行只扩大收件范围。规划仍归发起分行，经营场景选择范围和收件人的工作台可见规则沿用现状。

## Capabilities

### New Capabilities

- `wealth-excel-distribution` 提供白名单内的 Excel 名单分发。

### Modified Capabilities

无。

## Impact

涉及 Console 财富工作台创建与发布流程、外部智拓人员查询和规划发布服务。沿用现有发布请求结构，使用浏览器原生能力解析文件，无新增 npm 依赖。外部接口的真实契约由对接确认。
