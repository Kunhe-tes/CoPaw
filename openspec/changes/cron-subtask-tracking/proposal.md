## Proposal: 定时任务子任务跟踪系统

### 背景

部分定时任务会拆分成多个异步子任务执行，当前系统无法追踪这些子任务的独立状态，也无法将子任务执行结果汇总到主任务执行记录中。

### 解决方案

1. **新建子任务表 `swe_cron_subtasks`**
   - 存储每个子任务的 `task_id` 和状态
   - 通过 `trace_id` 与主任务关联

2. **扩展执行记录表**
   - 在 `swe_cron_executions` 添加 `async_status` 字段
   - 汇总子任务状态

3. **新增三个接口**
   - `POST /monitor/subtasks` - 写入子任务记录
   - `POST /monitor/subtasks/sync-status` - 同步子任务状态（调用外部API）
   - `POST /monitor/cron/executions/sync-async-status` - 汇总异步执行状态

4. **配置管理**
   - 外部 API URL、appKey、envTag、API-Key 存储在环境配置文件

### 影响范围

| 模块 | 变化 |
|------|------|
| 数据库 | 新表 + 新字段 |
| API | 3 个新接口 |
| 配置 | 4 个新增环境变量 |
