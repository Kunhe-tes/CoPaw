# W+ 页面索引

本索引只用于在澄清时定位可能相关的页面。必须让用户确认实际使用的页面、字段和业务含义。采集会话中的界面引用编号不稳定，因此不作为选择器保留。

## 商机中心

### 高价值动账

- 已观察路径：商机 → 商机中心 → 重要商机 → 高价值动账
- 已知视图：全部、待处理、已处理、已过期
- 已观察分类：他行同名、他行异名、行内转账、行外投资、公积金提取、三方银证、房产交易、非货基金实时赎回
- 注意：来源页面说明筛选功能处于维护状态，页面筛选不可用；适配器侧日期和金额筛选能力仍未验证。

## 客户洞察

可以从商机名单进入客户，但这只是页面观察结果，不代表必然存在可执行的 CLI 数据依赖。大多数客户洞察适配器都需要由用户确认或由前序已记录输出提供 `custUid`。

### 资产总览

- 已观察路径：客户洞察 → 资产总览
- 已观察标签页：资产总览、实时资产、资产明细、实时收支、最新收益
- 已观察内容：当前持仓、日均资产、持仓总收益、资产分类占比、资产走势
- 已知关键输入：`custUid`
- 注意：来源中的示例余额和比例属于具体客户数据，未予保留。

### 资产明细

- 已观察路径：客户洞察 → 资产明细
- 已知视图：资产组合（按日）、资产组合（按月）
- 已知关键输入：`custUid`

### 实时资产与实时收支

- 已观察路径：客户洞察 → 实时资产 → 实时收支
- 已观察内容：活期账户交易明细、实时产品交易
- 已知关键输入：`custUid`
- 注意：`real-time-balance` 与 `product-open-balance-current` 从不同页面上下文描述了相互重叠的活期流水数据。在契约验证完成前，应将其视为两个独立适配器。

### 最新收益

- 已观察路径：客户洞察 → 最新收益
- 已知视图：昨日、本月、今年、累计、收益日历、产品详情
- 已知关键输入：`custUid`
